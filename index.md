The **Bear and Moose Certificate Authority** (BMCA) project provides basic *Certificate Authority* functionality. Certificates are generated and can be installed on target systems to support SSL/TLS encryption. 

Use cases for **BMCA** include certificate management for active development teams, QA teams, and production environments.
